TexImage Sheet Creator
======================

Introduction
---

This is a very simple sprite generator for game developement. Its only function is to merge multiple PNG images of the same size into
a single PNG image according to the specified row and column positions. Its feature is that the file name and position of each PNG image
are assigned in an XML configuration file. This way, when you want to modify or replace the image further, you only need to edit the configuration file,
which is beneficial for project maintenance.
